# NAYA Trading AI — شروع واقعی پروژه

این بسته یک **نمونه اولیه قابل اجرا** است؛ هنوز سرویس آنلاینِ مستقرشده یا هوش مصنوعی آموزش‌دیده نیست.
نسخه فعلی داده کندل بازار را از Binance می‌گیرد و با قوانین شفاف تکنیکال، خروجی BUY / SELL / WAIT می‌سازد.
هیچ معامله‌ای اجرا نمی‌کند و کلید API صرافی نمی‌خواهد.

## امکانات فعلی
- دریافت کندل‌های واقعی از Binance برای نمادهای USDT
- تایم‌فریم پیش‌فرض ۱۵ دقیقه
- محاسبه EMA، RSI و ATR
- خروجی سیگنال، محدوده ورود، حد ضرر، هدف‌ها، نسبت سود به ریسک و توضیح
- انتخاب نماد از رابط وب
- مدیریت خطا و نمایش زمان آخرین به‌روزرسانی

## محدودیت مهم
این نسخه **AI واقعی یا سوددهی تضمین‌شده نیست**. موتور فعلی قانون‌محور است و هنوز بک‌تست معتبر، پایش پیوسته، هشدار موبایل، Gemini و اتصال TradingView به آن اضافه نشده‌اند. درصد برد نمایش داده نمی‌شود؛ تا وقتی بک‌تست خارج از نمونه و کالیبراسیون انجام نشده، چنین عددی گمراه‌کننده است.

## ساختار
- `worker.js` — بک‌اند Cloudflare Worker و تحلیل کندل‌ها
- `public/index.html` — رابط موبایل‌پسند
- `wrangler.toml` — پیکربندی استقرار
- `package.json` — دستورات توسعه

## اجرا و استقرار
برای استقرار آنلاین به حساب Cloudflare نیاز داری. می‌توانی این کار را با مرورگر گوشی هم انجام دهی، ولی کار با کامپیوتر راحت‌تر است.

### روش پیشنهادی
1. یک مخزن GitHub جدید بساز و فایل‌های همین بسته را در آن قرار بده.
2. در Cloudflare داشبورد، بخش Workers & Pages را باز کن و یک Worker بساز.
3. محتوای `worker.js` را در ادیتور Worker قرار بده و Deploy بزن.
4. در تنظیمات Worker، متغیر `FRONTEND_ORIGIN` را فعلاً روی `*` بگذار تا رابط آزمایشی بتواند درخواست بفرستد. برای استفاده واقعی، آن را به دامنه رابط محدود کن.
5. برای نمایش رابط، فایل `public/index.html` را در GitHub Pages یا Cloudflare Pages منتشر کن.
6. آدرس Worker را در `public/index.html` در مقدار `API_BASE` قرار بده.

### اجرای محلی (با Node.js و Wrangler)
```bash
npm install
npm run dev
```
این دستور Worker را روی محیط توسعه اجرا می‌کند. برای رابط استاتیک، پوشه `public` را جداگانه با یک سرور استاتیک اجرا کن.

## ایمنی
- نسخه فعلی فقط تحلیل و سیگنال می‌دهد؛ معامله خودکار ندارد.
- از این خروجی برای سفارش واقعی بدون بک‌تست، paper trading و کنترل ریسک استفاده نکن.
- هیچ API key خصوصی صرافی را در HTML یا کد عمومی قرار نده.
- API عمومی Binance ممکن است در برخی کشورها یا شبکه‌ها در دسترس نباشد.
